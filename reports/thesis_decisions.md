# Thesis decisions and open questions

## Current decisions

| Area | Current position | Status |
|---|---|---|
| Task | Binary actionable defect/vulnerability flagging | Working decision |
| Primary candidate | PrimeVul | Provisional |
| Development order | Baseline → calibration → abstention → corroboration | Adopted |
| Calibration methods | Temperature scaling and Platt scaling | Planned |
| Final evaluation | Locked held-out partition | Required |
| Static analysis | CodeQL or SonarQube, after the preceding stages | Planned |

## Open questions before implementation

1. Obtain the actual PrimeVul train, validation, and test files in the Codex-accessible project folder. **Completed.**
2. Reproduce record counts, class distributions, schema, missingness, and code-length statistics. **Completed for the raw partitions.**
3. Measure exact and near-duplicate leakage across every supplied partition. **Exact and approximate/verified triage completed; semantic leakage classification remains open.**
4. Decide whether the supplied partitions can serve as development, calibration, and final-test roles.
5. Freeze the prompt, model version, output schema, random seeds, and evaluation code.
6. Define the conformal nonconformity score and state precisely what coverage guarantee is being claimed.
7. Select the initial static analyzer and define how no-result/unsupported-code cases map to the corroboration categories.
